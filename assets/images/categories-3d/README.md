# Category artwork

Generated with the built-in imagegen tool from the approved realistic 3D category preview. Each PNG is a separate transparent asset, optimized to a maximum edge of 512 pixels. Subjects are listed in `manifest.json`; spice and snack artwork is reused for the corresponding duplicate categories.

The app uses these icons in place of the original supplied category URLs. Later admin uploads take precedence. The same PNGs are available in the admin project's `public/category-icons-3d/` folder, and its existing **Apply category icons** action uploads this set to Supabase.

## Generation prompt

For each asset, replace the flour subject below with its `subject` from the manifest. The attached reference was the approved 3D category screen preview.

Use case: stylized-concept. Asset type: one square mobile grocery category icon. The attached screenshot is ONLY a style reference for its dimensional baskets; do not reproduce any interface, labels, tiles or phone. Generate ONE isolated premium realistic 3D rendered yellow basket of flour paper sacks, a small bowl of white flour and wheat ears. Match the screenshot's rounded slotted plastic basket, strong three-quarter perspective showing front and right side, warm studio lighting upper left, realistic object materials, restrained glossy reflections, rich yellow/lime palette, ambient occlusion and soft contact shadow. Center entire basket and contents, occupy 82% of square canvas with equal margins and no clipping. Genuine transparent background, no colored tile or ground plane. No text, letters, logos, brands, watermark, UI or border. Detailed but readable at 64px.
